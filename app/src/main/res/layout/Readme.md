# Login Screen App

## Project Overview
A simple Android login screen UI developed using Kotlin and XML for the Veda Technology Android Development Track (Day 3).

## Technologies Used
- Kotlin
- XML Layouts
- Android Studio

## Features
- Email input field
- Password input field
- Login button
- Forgot Password text
- Registration option text

## How to Run
1. Clone the repository.
2. Open in Android Studio.
3. Sync Gradle.
4. Run the app on a device or emulator.

## Outcome
The application successfully displays a clean login screen UI with all required components.
